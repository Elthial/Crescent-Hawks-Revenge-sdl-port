# Original game files go here

For a separated development layout, copy or install your legally obtained
*BattleTech: The Crescent Hawks' Revenge* files into this directory. The
repository's `Run-Revenge.ps1` launcher uses this location by default.

For a packaged executable, set `asset_directory` in the `REVENGE.CFG` beside
`Revenge.exe` to the relative or absolute path of this directory.

The supplied original files are ignored by Git. They are not part of this
preservation source repository and must not be committed or redistributed.
`MEDIA.CFG` must be present, and ordinary gameplay requires the rest of the
original installation's data files as well.
