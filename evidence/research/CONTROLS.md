# Controls

This page normalizes the user-supplied keyboard reference card transcription.
The external [reference-card text](https://d1.xp.myabandonware.com/f/lrrs/BattleTech-The-Crescent-Hawks-Revenge_RefCard_DOS_EN_Keyboard-Controls.txt)
was unavailable during this research pass, so the transcription is the current
source of record.

| Keyboard | Mouse | Action |
| --- | --- | --- |
| arrow keys | screen edge | scroll orthogonally |
| diagonal key direction | screen corner | scroll diagonally |
| Space or Enter | left button | select |
| Escape | right button | unselect; opens options if no 'Mech is selected |
| F1–F4 | — | center on units 1–4 of lance 1 |
| F5–F7 | — | switch control to lances 1–3 |
| F9 | — | center on visible enemies |
| F10 | — | DropShip controls |
| `-` or `*` | — | cycle among units on screen |
| 1–8 | — | game speed, slowest to fastest |
| Alt+S | — | sound effects on/off |
| Alt+M | — | music on/off |
| Alt+V | — | digitized voice on/off |

The original transcription labels both `-` and `*` as cycling among on-screen
units. Confirm direction and keypad/main-key behavior in DOSBox-X before binding
them in a reimplementation.
